# НЕОН-РЕЙС 5.5 — отдельная сборка VK Games (ВКонтакте + Одноклассники)

Эта папка содержит отдельную HTML-сборку игры для VK Mini Apps / VK Games. Она создана на основе опубликованной версии 5.5, но не заменяет и не изменяет версию Пикабу.

## Что сохранено из игры 5.5

- Механика только уклонения: нет стрельбы, оружия и уничтожения препятствий.
- Баланс, цены кораблей и уровни разблокировки версии 5.5.
- Награда за подтверждённый rewarded-просмотр: +50 кристаллов.
- Русский и английский языки, адаптация под телефон и компьютер.

## Изоляция сборки

- Входная страница: `index.html`.
- Локальные данные: `neonRaceProgress_vk_v1`, `neonRaceLanguage_vk`, `neonRaceSound_vk`.
- Облачный ключ VK Bridge: `neonRaceProfile_vk_v1`.
- Данные Пикабу остаются в прежнем ключе `neonRaceProgress_v3` и в Пикабу SDK; VK-сборка их не читает и не перезаписывает.
- Рабочая версия Пикабу остаётся в корневом `index.html` на ветке `main`.

## VK Bridge

Используется официальный browser bundle `@vkontakte/vk-bridge@3.0.2`:
- `https://unpkg.com/@vkontakte/vk-bridge@3.0.2/dist/browser.min.js`
- резервный CDN: `https://cdn.jsdelivr.net/npm/@vkontakte/vk-bridge@3.0.2/dist/browser.min.js`

При запуске вызывается `VKWebAppInit`. Облачное сохранение использует `VKWebAppStorageGet` и `VKWebAppStorageSet`; изменения записываются последовательно, при скрытии/закрытии игры выполняется попытка синхронизации.

ОК определяется параметром `vk_client=ok`. Поддерживаемые возможности проверяются через VK Bridge, а не предполагаются заранее.

## Реклама

- Rewarded: `VKWebAppCheckNativeAds` / `VKWebAppShowNativeAds`, `ad_format: "reward"`.
- Interstitial: те же методы с `ad_format: "interstitial"`.

Кристаллы начисляются только при подтверждённом результате rewarded-вызова `result: true`. Межстраничная реклама ограничена интервалом не чаще одного показа за 120 секунд, а доступность дополнительно проверяется у платформы.

**Ограничение ОК:** официальная таблица совместимости отмечает `VKWebAppCheckNativeAds` и `VKWebAppShowNativeAds` только для Android. На вебе и iOS ОК рекламные форматы автоматически отключаются, если среда не поддерживает методы. В VK доступность зависит от среды запуска и настроек рекламных размещений. Рекламу нужно отдельно проверить внутри приложения.

## Проверки перед публикацией

1. Создать VK Mini App в кабинете разработчика VK.
2. Разместить корень нового репозитория на отдельном HTTPS-адресе. Не менять GitHub Pages, обслуживающий Пикабу.
3. Указать URL игры в настройках VK Mini App и проверить запуск внутри клиента VK.
4. Включить публикацию приложения в Одноклассниках и привязать профиль разработчика ОК.
5. Проверить отдельно в ОК Android, web и iOS: запуск/пауза, облачное сохранение, доступность рекламы.
6. Проверить загрузку облачного сохранения на втором устройстве и поведение при недоступном SDK.

## Пока не включено

- Глобальные таблицы лидеров: рекорды сохраняются в локальном и облачном профиле. Для публичного рейтинга нужен отдельный проект API/серверной части.
- VK ID и VK Pay в ОК: документация ОК сообщает, что эти сервисы не реализованы для кроссплатформенных VK Mini Apps.
- Автоматический перенос прогресса из Пикабу: намеренно не выполняется, чтобы профили платформ не смешивались.
