# НЕОН-РЕЙС 5.5 — VK Games

Самостоятельная сборка НЕОН-РЕЙС 5.5 для публикации через **VK Mini Apps / VK Games** во ВКонтакте и Одноклассниках.

## Играть

После активации GitHub Pages:
https://jokordo56ru.github.io/neon-race-vk-games/

Главный файл игры — `index.html` в корне этого репозитория.

## Что внутри

- Полная браузерная игра НЕОН-РЕЙС 5.5.
- Интеграция VK Bridge 3.0.2: инициализация, облачное сохранение, управление жизненным циклом и проверка доступности рекламы.
- Поддержка запуска в ОК через параметр `vk_client=ok`.
- Отдельные ключи локального/облачного сохранения VK.
- Награда за подтверждённый rewarded-просмотр — +50 кристаллов.

Механика НЕОН-РЕЙС не менялась: игрок уклоняется от препятствий, собирает звёзды и развивается. Оружия и стрельбы нет.

## GitHub Pages — один раз включить источник

1. Открой **Settings → Pages**.
2. В блоке **Build and deployment** выбери **GitHub Actions** в поле **Source**.
3. После сохранения workflow `.github/workflows/pages.yml` опубликует игру.
4. Статус смотри во вкладке **Actions**.

Дальнейшие изменения в `main` будут публиковаться автоматически.
